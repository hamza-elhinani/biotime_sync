⚙️ Quick Setup

  1. Install the module from Apps menu
  2. Go to Biotime Sync → Configuration
  3. Enter your Biotime server URL and authentication credentials
  4. Configure business rules (work hours, break duration, tolerances)
  5. Map employees by setting their Biotime ID
  6. Click Test Connection to verify the setup
  7. Run manual sync or enable automatic synchronization

📋 Business Rules

Setting Description
Work Start/End Time Define standard working hours for late detection
Break Duration Automatic break deduction from worked hours
Late Tolerance Grace period before marking attendance as late
Overtime Threshold Hours after which overtime is calculated
Sync Interval Frequency of automatic synchronization
